# Security policy / Política de segurança

## Reporting / Relato

Do not disclose vulnerabilities in public issues. Use GitHub's private vulnerability reporting for
`ViaPost-io/viapost-python`, or contact the security channel listed at
[viapost.io](https://viapost.io).

Não divulgue vulnerabilidades em issues públicas. Use o relato privado de vulnerabilidades do
GitHub em `ViaPost-io/viapost-python` ou o canal de segurança indicado em
[viapost.io](https://viapost.io).

## Supported versions / Versões suportadas

Security fixes are provided for the latest released minor version. Never expose a ViaPost API key
in browser, mobile, client-side, exception, or shared-log output.
